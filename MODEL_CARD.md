# Model Card — MiMoLite-SFT-v8

<!-- 中文摘要 -->
**中文摘要**：MiMoLite 是一个从零预训练、参数约 106M 的代码生成语言模型。v8 为当前最佳版本：
自建 100 题代码评测集上 pass@1 = 29%、pass@8 = 57%、pass@16 = 59%；3 个随机种子重复验证
均值 pass@1 = 28%、pass@8 = 56%（结论非单点噪声）。全程不蒸馏、不改结构，只在数据侧迭代，
单张 RTX 5070 8GB 完成。标准英文基准（HumanEval / MBPP）上为 0%，存在明确的外分布泛化鸿沟，
本卡如实披露（详见研究报告 4.4）。

## Model Overview

- **Name**: MiMoLite-SFT-v8
- **Task**: Code generation (Python, function-level, Chinese instructions)
- **Parameters**: 108.16M (training scope, without MTP) / 110.12M (exported weights, incl. MTP)
- **Precision**: FP16 (GGUF)
- **Model type**: From-scratch pretrained + SFT transformer, **no distillation**
- **Hardware used**: a single RTX 5070 Laptop 8GB (compute capability 12.0)
- **License**: MIT (weights, code and self-authored data; see `LICENSE` and `NOTICE`)

## Intended Use

- Research and education: data-centric LLM engineering, small-model behavior, curriculum / budget effects.
- Local inference demo via llama.cpp (see below).
- **Not** for production use; the model is too small and too narrow (see Limitations).

## Training Data

- **Self-authored rule-based synthetic code data** (template programs, deduplicated, seed 7/8/9):
  released in this repo under MIT (`data/synth_code_*.jsonl`).
- Base model pretraining corpus: cleaned Chinese+English Wikimedia / Gutenberg subsets —
  **not redistributed** in this repo (see `NOTICE.md`).
- **No teacher distillation**: no data generated by a larger LLM.

## Training Procedure

| Stage | Steps / Epochs | Notes |
|---|---|---|
| Pretraining (a001_B1_v2) | 4500 steps | zh:en 75:25 dynamic mix, ~148M tokens |
| SFT (sft_v8) | 10 epochs (330 steps) | 600 template variants + eval-frequency weighting (HOT16/others 6) |

Reproducible pipeline: `scripts/synth_code_tpl.py` → `scripts/build_train_v2.py` → `scripts/prepare_sft.py`
→ `sft.py --ckpt runs/a001_B1_v2/final.pt --epochs 10` (see README "复现主线").

## Architecture

8 layers / d_model 960 / GQA (15 query heads, 5 KV heads, d_head 64) / SWA:GA = 6:1 (window 128) /
SwiGLU / RoPE (interleaved) / MTP depth 1 (weight 0.3) / tied embeddings. Vocab 16,384.

## Evaluation

In-distribution benchmark (self-built 100 problems, same training distribution):

| Version | pass@1 | pass@8 | pass@16 |
|---|---:|---:|---:|
| base (pretrain only) | 0 | 0 | 0 |
| **sft_v8 (best)** | **29/100 (29%)** | **57/100 (57%)** | **59/100 (59%)** |
| sft_v9 (negative) | 20 | — | — |
| sft_v10 (negative) | 28 | 51 | — |

Multi-seed robustness (same data pipeline, 3 seeds): pass@1 mean **28%**, pass@8 mean **56%**.

**Out-of-distribution anchor (honest disclosure)**: HumanEval 0/164 (p1 & p8), MBPP 0/257 (p1 & p8).
The gap confirms capabilities are bound to the training distribution (question–function-name
combinations) and do not yet generalize cross-distribution. Evaluation protocol
(instruction-adapted prompting, low-temperature single sampling) is fully disclosed in the report §4.4.

**Negative results (kept, not hidden)**: 4 GRPO rounds at 106M+8GB concluded RL is not yet viable
(sparse rewards, no strong teacher signal); v9/v10 prove the "budget conservation law"
(strengthening A within a fixed budget necessarily weakens B).

## Known Limitations

1. Zero performance on standard English benchmarks (HumanEval / MBPP) — no cross-distribution
   generalization yet.
2. Instruction-following is brittle: the model may leak Chinese trailing words ("即可。") into code,
   causing syntax errors (diagnosed in report §4.4).
3. Tiny model — long multi-step reasoning, tool use and chat are out of scope.
4. Chinese-path pitfalls when loading with llama.cpp (documented in README).

## Ethical & Safety Notes

The model is a research artifact with very limited capability; it cannot produce harmful
instructions, follow complex prompts, or act as an agent. No special risks identified beyond
generic small-model biases from the training corpus (Wikipedia / Gutenberg / synthetic code).
Dataset licensing obligations are tracked in `NOTICE.md`.
